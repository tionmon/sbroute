# 性能与验证记录

以下为开发环境中已完成的验证，不代表公网节点的带宽或所有协议的占用。CI 以手动触发方式提供。

## 环境与负载

- Linux 5.4，amd64，2 vCPU（AMD EPYC 7C13），约 6GB 主机内存。
- Go 1.26.4，官方 sing-box 1.14.4，构建标签 `with_quic,with_utls`。
- 连接保持测试单独限制在 1GiB cgroup 内、CPUQuota=200%、LimitNOFILE=131072。
- 负载使用真实回环 TCP socket：客户端 → 核心固定目标入口 → 本机 echo 服务。客户端和 echo 也在测试进程中，因此内存与 CPU 包含夹具开销。
- 配置共 300 个节点、20 个入口；其中一个显式本地直连测试节点承载流量，299 个未引用代理节点保持冷态。此数据不代表 300 个已经预热的 QUIC 连接池。

## 连接规模

| 阶段 | 进程 RSS |
| --- | ---: |
| 300 节点配置、20 入口，空闲 | 26.1 MiB |
| 1,000 TCP 连接 | 51.5 MiB |
| 5,000 TCP 连接 | 133.5 MiB |
| 10,000 TCP 连接 | 238.9 MiB |
| 10,000 连接保持 30 分钟结束 | 235.5 MiB |

30 分钟测试通过，过程中持续抽样收发数据，结束关闭连接后业务计数归零。10,000 连接阶段 cgroup 总占用曾约 839MiB，进程约 6 个系统线程、约 30,134 个 goroutine。后续观察 FD 约 90,555，包含 echo、Linux splice pipe 与客户端夹具；不能把它当作生产单侧代理的每连接 FD 数。

加入 cgroup 与 FD 监控后的最终版本另在 1GiB 限制下完成了 10,000 连接、60 秒保持复测：空闲 RSS 25.2MiB，1,000 / 5,000 / 10,000 连接时分别约 47.1 / 139.3 / 249.8MiB，保持结束约 264.7MiB，测试通过。

## 原生核心对比

同一版本、同一编译选项、同一进程内 32KiB TCP echo 循环，三次采样取中位数。MB/s 按一方向的业务 payload 计数；实际 echo 同时有上下行。CPU/GiB 是整个测试进程的 user+system CPU 时间，含客户端与 echo。

| 路径 | payload MB/s 中位数 | CPU 秒/GiB 中位数 |
| --- | ---: | ---: |
| 原生 sing-box direct inbound/outbound | 1529.32 | 0.7022 |
| SBRoute 轮询 | 1527.41 | 0.7027 |
| SBRoute 随机 | 1453.73 | 0.7394 |
| SBRoute P2C | 1468.77 | 0.7324 |
| SBRoute IP 哈希 | 1593.07 | 0.6750 |
| SBRoute 最小连接数 | 1540.66 | 0.6989 |

初轮与复测中，各策略中位数的吞吐损失均在 10% 目标内；初轮轮询约 6.6%，复测约 0.1%，说明短时循环基准存在调度噪声。表中小幅领先不能证明调度层让核心本身更快。长连接仅在建连时选择节点，转发阶段的差异主要来自计数及后台管理。

独立的 300 节点池选择基准中，轮询约 6ns、随机约 17ns、P2C 约 30ns、IP 哈希约 110ns、最小连接数约 1.5µs。选择基准均报告 0 B/op、0 allocs/op。转发基准报告 0 allocs/op，后台分配摊销约 0–20 B/op；这不表示整个进程从不分配内存。

## 已完成的功能验证

- Linux 全项目 `go test -race` 通过，Go vet 通过，模块校验通过。
- HTTP CONNECT 认证、SOCKS TCP、固定目标 TCP/UDP；SOCKS5 UDP association 跨目标保持出口，超过 10 秒握手期限后仍可使用。
- SS、VLESS/TLS、Hysteria2、TUIC 对接本地原生服务端，TCP 与 UDP 实际收发通过。
- 域名目标、IPv6 目标与 IPv6 来源白名单；六种策略、稳定哈希、共享池、并发准入计数。
- 100 次策略更新保留现有连接，100 次节点版本更新后旧对象数量有界；占用端口应用失败保留旧入口；空组没有直连。
- 订阅改名、重复项、空结果、大规模删除审核、配置版本冲突、回滚、登录/退出、CSRF、脱敏响应、备份及无效恢复保护。
- 导入解析器 30 秒模糊测试，约 569,919 次执行，无崩溃。
- 前端两项交互测试通过；Linux Chromium 真实端到端验证登录、导入、建组、建入口、资源预设、版本回滚、桌面/手机布局和退出登录。
- 前端依赖审计在构建时为 0 项；前端生产包约 270KB JS，预压缩 gzip 约 84KB。

## 尚未作为结果声称的内容

没有使用真实机场订阅做长期 WAN 质量测试，也没有完成全部加密协议各自的高并发吞吐矩阵。Docker 模板未在测试机启动验证；arm64 为交叉编译，未在 arm64 硬件运行。重启/升级不能保留连接，同端口修改协议、认证、固定目标或 UDP 超时需先禁用入口并保存。
